# ToTB Link

Windows PC 화면 스트리밍과 USB 장치 연결을 위한 ToTB Link 공식 배포 저장소입니다.

[최신 버전 다운로드](https://github.com/DANDAN-TT/ToTB-Link/releases/latest)

- 서버 PC: `ToTBLink-Server.exe`
- 클라이언트 PC: `ToTBLink-Client.exe`
- 서버와 클라이언트 묶음: 릴리스의 ZIP 파일

기존 배포처에서 사용하던 앱은 새 배포본을 한 번 직접 다운로드해 교체해주세요. 1.0.12부터 이 저장소에서 자동 업데이트를 확인합니다.
